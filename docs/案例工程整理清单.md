# 案例工程整理清单

## 怎么整理的

用 TouchDesigner 自带的 `toeexpand` / `toecollapse` 把 `.toe` 展开成文本，在文本里改素材路径，再合回去。合回去前先用两个工程试过：原样展开再合回，内容完全一致（1938 个文件一个不差），说明这一步不会丢东西。

每个案例都做了这几件事：

1. 主工程按英文短名改名，只留一个在第一层（比如 `CASE06_Pixel Gem/PixelGem.toe`）
2. 工程里用到的素材**复制**进 `assets/images | videos | audio | models`，组件进 `tox/`（MediaPipe 放 `tox/mediapipe/`），脚本进 `scripts/`，参数改成新的相对路径
3. 录制输出（Movie File Out）的路径统一改到 `export/`
4. 删掉嵌在工程里的 TDMCP（它带着你电脑用户名的路径，不该卖给买家）
5. 合成新工程后再展开核对一遍：每个引用都指向工程文件夹里真实存在的文件
6. 原来的 `.toe` 和用不到的旧文件夹挪进 `_旧结构/`，放在一起，**旧工程在 `_旧结构/` 里照样能打开**；演示视频挪进 `demo/`
7. 每个案例写了 `_整理记录.json`：哪个文件从哪来、到哪去、改了哪个参数，照着可以撤回

没有删除任何你的文件。`_旧结构/` 确认不用了再自己删，一共约 4.3 GB。
