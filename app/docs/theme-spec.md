# TD 工程启动器 · 主题制作规范

主题只换颜色和左上角的标志，不改布局、字体和形状。一个主题是一个 JSON 文件，里面必须同时有浅色（`light`）和深色（`dark`）两套颜色。

## 1. 文件放哪里

| 种类 | 位置 | 生效方式 |
| --- | --- | --- |
| 自己做的主题 | 设置 → 主题 → "打开主题文件夹" 打开的那个文件夹 | 放进去后在设置里点"重新读取"，不用重装软件 |
| 软件自带的主题 | 源码的 `app/src/themes/`，并在 `index.json` 里登记文件名 | 重新打包 |

- 文件名随意，必须以 `.json` 结尾，用 UTF-8 保存。
- 以 `_` 开头的文件会被跳过，`_template.json` 就是给你复制用的模板。
- 单个文件不超过 64 KB。

## 2. 最小的主题

复制 `_template.json`，改个名字，再改 `id`、`name` 和颜色就能用：

```json
{
  "format": 1,
  "id": "my-theme",
  "name": "我的主题",
  "description": "一句话说明",
  "light": { "bg0": "#E9E9E5", "bg1": "#F4F4F1", "bg2": "#FFFFFF", "line": "#D9D9D3", "line2": "#C9C9C3",
             "ink": "#111111", "ink2": "#45453F", "mute": "#6B6B65", "faint": "#8E8E88", "onInk": "#FFFFFF" },
  "dark":  { "bg0": "#0E0E0D", "bg1": "#171716", "bg2": "#20201E", "line": "#2C2C29", "line2": "#3D3D39",
             "ink": "#F2F2EE", "ink2": "#C4C4BD", "mute": "#96968F", "faint": "#73736D", "onInk": "#111111" }
}
```

## 3. 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `format` | 是 | 固定写 `1`。以后格式有不兼容的改动才会变 |
| `id` | 是 | 主题的唯一标识：小写字母、数字、连字符，2 到 32 个字符。不能和别的主题重复 |
| `name` | 是 | 显示在设置里的名字，建议 6 个字以内 |
| `description` | 否 | 名字旁边的一句小字 |
| `logo` | 否 | 主题自带的标志，见第 6 节 |
| `light` | 是 | 浅色模式的颜色 |
| `dark` | 是 | 深色模式的颜色 |

## 4. 必填的 10 个颜色

`light` 和 `dark` 里都要写全，格式是 6 位十六进制（`#RRGGBB`）。

| 名字 | 用在哪里 |
| --- | --- |
| `bg0` | 最底层：主区域的背景 |
| `bg1` | 面板：侧栏、标题栏、弹窗、抽屉 |
| `bg2` | 卡片、输入框、未选中的按钮 |
| `line` | 细分割线、输入框的描边 |
| `line2` | 更明显的线：分组标题下的线、次要按钮的描边 |
| `ink` | 主文字，同时也是强调色：主按钮、选中项的底色 |
| `ink2` | 次要文字 |
| `mute` | 说明文字 |
| `faint` | 最弱的文字：日期、英文小标签 |
| `onInk` | 压在 `ink` 底色上的文字和图标 |

层级关系要成立：

- 浅色模式：`bg0` 最暗，`bg1` 稍亮，`bg2` 最亮。
- 深色模式：`bg0` 最暗，`bg1` 稍亮，`bg2` 最亮（卡片比背景亮一点，才浮得起来）。
- 文字从强到弱：`ink` → `ink2` → `mute` → `faint`。

## 5. 可选的颜色

不写的话软件会根据上面 10 个颜色自动算出来，一般不用管。想精修再写。

| 名字 | 用在哪里 | 不写时怎么算 |
| --- | --- | --- |
| `inkHover` | 主按钮悬停时的底色 | `ink` 往 `onInk` 混一点 |
| `inkLine` | `ink` 底色上的分隔线（批量操作栏） | `ink` 往 `onInk` 混一点 |
| `onInkMute` | `ink` 底色上的次要文字 | `onInk` 往 `ink` 混一些 |
| `hover` | 侧栏条目悬停时的底色 | `bg1` 往 `ink` 混一点 |
| `thumb` | 缩略图后面的底色 | 浅色模式是近黑，深色模式比 `bg0` 更暗 |
| `scroll` / `scrollHover` | 滚动条 | `line2` / `faint` |
| `skel1` / `skel2` | 扫描时占位条的颜色 | `bg2` 往 `ink` 混一点 |
| `lift` | 卡片悬停时底下的投影 | 半透明的 `ink` |
| `scrim` | 弹窗后面的遮罩 | 半透明的深色 |

这几项除了 `#RRGGBB`，还可以写 `rgba(…)`，比如 `"lift": "rgba(17,17,17,.08)"`。`lift` 写成不透明的颜色时，投影是一条实心的边（玉主题就是这样做出"厚度"的）。

## 6. 标志

主题可以自带一个标志，显示在左上角。

```json
"logo": "my-logo.svg"
```

或者浅色、深色各用一个：

```json
"logo": { "light": "my-logo-light.svg", "dark": "my-logo-dark.svg" }
```

- 图片文件和主题的 `.json` 放在同一个文件夹，只写文件名，不能带路径。
- 支持 SVG 和 PNG。推荐 SVG；PNG 用透明底，高度至少 160 像素。
- 显示高度是 40 像素，宽度最多 80 像素，所以标志在很小的尺寸下也要认得出来。
- 用户在"设置 → 标志"里选了自己的图片时，以用户选的为准。
- 主题的标志不会用到工程文件夹图标上。

## 7. 对比度

软件不会替你检查对比度，交付前自己对一遍。数值指 WCAG 的对比度比值，可以用任何在线的对比度检查工具算。

| 组合 | 最低要求 |
| --- | --- |
| `ink` 在 `bg0`、`bg1`、`bg2` 上 | 7 : 1 |
| `ink2`、`mute` 在 `bg1`、`bg2` 上 | 4.5 : 1 |
| `faint` 在 `bg1`、`bg2` 上 | 3 : 1 |
| `onInk` 在 `ink` 上 | 7 : 1 |
| `line2` 在 `bg0` 上 | 看得出来即可，建议 1.3 : 1 以上 |

## 8. 做完检查

- [ ] `id` 没有和别的主题重复
- [ ] `light` 和 `dark` 各写全了 10 个必填颜色
- [ ] 两种模式都切过去看了：卡片墙、侧栏选中项、新建工程弹窗、工程详情、设置、批量操作栏、提示条
- [ ] 主按钮上的字看得清（`onInk` 压在 `ink` 上）
- [ ] 日期和小标签（`faint`）没有淡到看不见
- [ ] 有标志的话，两种模式下都看得清

## 9. 读不出来的时候

设置的主题一栏会列出没读成功的文件和原因，常见的有：

- 不是合法的 JSON：多半是多了或少了逗号、引号用成了中文引号。
- `缺少 light.ink` 这一类：必填颜色没写全。
- `颜色写法不对`：必填的 10 个颜色只接受 `#RRGGBB`。
- `id 和已有主题重复`：换一个 `id`。
